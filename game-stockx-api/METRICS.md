## После обновления backend

- `successful_add_to_collection_total` — реально вставленные строки коллекции. Повторное добавление не учитывается.
- `successful_add_to_wishlist_total` — реально вставленные строки вишлиста. Повторное добавление не учитывается.
- `wts_saves_total` — успешные сохранения WTS, включая редактирование. Старый смешанный `successful_add_to_wts_total` удалён.
- `successful_logins_total` — успешные входы. `failed_login_attempts_total{reason}` — отказы с причинами `invalid_password`, `user_not_found`, `database_error`. Логины и IP удалены из меток.
- Удалены дублирующий `login_attempts_total` и неработающие `login_attempts_by_ip_total`, `db_pool_connections`.
- `chat_messages_sent_total` — сообщения после успешной записи в БД. Добавлен `chat_message_persistence_errors_total` для ошибок записи/получения соединения. Порядок доставки сообщений не изменён.
- `ws_connections` — уникальные логины с активными WebSocket-сессиями внутри одного процесса, не число вкладок и не DAU. Уточнён HELP.
- `http_requests_total` и histogram используют шаблоны маршрутов, например `/api/products/{id}`. Неизвестные пути объединены в `unmatched`, нестандартные HTTP-методы — в `OTHER`. Ошибки middleware считаются по своему HTTP-коду, а не всегда как 500.
- Бизнес-счётчики регистрируются при запуске с нулём, чтобы не появляться только после первого события.

Имена основных метрик сохранены, но старые данные автоматически не исправляются. После деплоя выбирайте период начиная с обновления backend. Старые ряды с логинами, IP и конкретными путями останутся в истории Prometheus до истечения срока хранения.

Панели заявок совместимы с конкретными ID в старых рядах и новым шаблоном `{id}`. Панели коллекции и вишлиста теперь используют исправленные счётчики; график активности по-прежнему показывает успешные HTTP-операции, включая повторы.

## Проверка

`cargo test --locked` проверяет группировку маршрутов с разными ID, неизвестные пути и HTTP-коды ошибок middleware, а также существующие тесты приложения.

`cargo clippy --locked --all-targets -- -D warnings` проверяет сборку всех целей без предупреждений.

После деплоя проверьте scrape в Prometheus. В новых рядах endpoint должен содержать шаблон, а failed_login_attempts_total — только метку reason (и target labels Prometheus).
